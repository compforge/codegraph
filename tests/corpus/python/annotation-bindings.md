## 原因与修复范围

原遮蔽判断把 `parameters` 下的同名标识符一律当成绑定，因而 `value: Model` 使 `Model`
在整段函数内被误判为局部参数。引用提取也将带类型及可变参数的部分绑定名误当成读取。

参数处理现在分别提取绑定名和类型/默认值表达式：

- 参数绑定作用于函数体；签名里的读取使用外层作用域，函数体的局部赋值不污染自身签名。
- 嵌套函数签名仍检查外层参数，真实遮蔽继续阻止同名目标绑定。
- 类型注解、泛型/联合类型、默认值和返回注解保留读取；参数名字不再生成读取事实。
- Lambda 默认值中的调用不再被整段 lambda 的延迟执行范围覆盖，函数体仍保留原有缺口。

字符串注解、动态类型求值及完整的 Python 注解运行时语义未扩展。
实例方法引用、f-string 读取和其余写入位置误提取等缺口仍需分别处理。
